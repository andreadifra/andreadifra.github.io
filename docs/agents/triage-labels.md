# Triage Labels

Use these canonical labels for issue triage in this repository.

## Mapping

- `needs-triage`: maintainer needs to evaluate the issue
- `needs-info`: waiting on the reporter for more details
- `ready-for-agent`: ready for an AFK agent to pick up
- `ready-for-human`: ready for a human to implement
- `wontfix`: will not be actioned

## Consumer rules

- Apply the label that best matches the issue's current state.
- Do not invent alternate labels unless the repository explicitly adopts them.
- If the GitHub repository already has equivalent labels, map to those exact
  names instead of creating duplicates.
