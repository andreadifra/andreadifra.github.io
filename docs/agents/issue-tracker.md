# Issue Tracker

This repository uses GitHub Issues as the source of truth for tracked work.

## Consumer rules

- Create and update issues in the repository's GitHub Issues.
- Prefer the `gh` CLI for automation when a tool needs to create or update issues.
- Link issues back to the relevant Quarto pages, posts, or scripts in this repo when possible.
- Treat issue titles and descriptions as the canonical work record for open tasks.

## Scope

- Repository: `andreadifra/andreadifra.github.io`
- Tracker: GitHub Issues
